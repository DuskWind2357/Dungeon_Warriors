### 3.3 技术细节

#### 3.3.1 楼层缩放公式

```python
# 基础难度
base_hp_scale = 1.18  # 每层+18%
base_atk_scale = 1.18
base_cd_scale = 0.99  # 每层-1%
base_skill_cd_scale = 0.99

# 冒险难度
adventure_hp_scale = 1.18
adventure_atk_scale = 1.18
adventure_cd_scale = 0.985  # 每层-1.5%
adventure_skill_cd_scale = 0.985

# 末日难度
doom_hp_scale = 1.26  # 每层+26%
doom_atk_scale = 1.26
doom_cd_scale = 0.98  # 每层-2%
doom_skill_cd_scale = 0.98

# 应用公式
hp = base_hp * (hp_scale ** (floor_num - 1))
atk = base_atk * (atk_scale ** (floor_num - 1))
cd = base_cd * (cd_scale ** (floor_num - 1))
skill_cd = base_skill_cd * (skill_cd_scale ** (floor_num - 1))
```
