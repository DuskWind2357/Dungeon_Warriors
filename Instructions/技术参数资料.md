## 二、操作键位

| 按键 | 功能 |
|------|------|
| WASD | 移动 |
| 鼠标左键 | 近战攻击（自动朝向鼠标）；**长按自动连续出招**（仅近战） |
| 鼠标右键 | 远程攻击（单击单发，无长按连射） |
| 数字键 1-5 | 快捷使用消耗品：1 面包 / 2 生命药水 / 3 力量药水 / 4 迅捷药水 / 5 隐身药水 |
| E | 拾取地上物品（1.5 格范围内取最近） |

## 三、玩家参数

### 基础属性
| 属性 | 值 |
|------|-----|
| 基础 HP | 100（PLAYER_BASE_HP） |
| 基础移速 | 4 px/帧（PLAYER_BASE_SPEED） |
| 全局移速倍率 | 0.75（GLOBAL_SPEED_MULT，玩家与怪物统一缩放；玩家实际位移 = total_speed()×0.75） |
| 初始装备 | 铜剑（+4）+ 弩（普通）（+8）+ T1 护甲五类随机一件 |
| 复活（生命条数） | 3 条上限（MAX_REVIVES）；复活倒计时 5 秒；复活后 HP 回满、装备保留、楼层重置 |
| 游戏结束 | 无生命条数时死亡 → 3 秒后自动返回主菜单，存档删除 |

### 玩家成长（V1.0.5.10 起按难度取值）
| 参数 | 默认 | 冒险 | 末日 |
|------|------|------|------|
| 攻击加成/层 | +4% | +5% | +6% |
| 攻击加成/精英击杀 | +1% | +1% | +1% |
| 攻击加成/头目击杀 | +9% | +12% | +15% |
| 生命加成/层 | +5 | +8 | +10 |
| 生命加成/精英击杀 | +2 | +3 | +5 |
| 生命加成/头目击杀 | +10 | +15 | +20 |

### 公式
```
HP  = round((100 + (floor-1)×每层生命加成 + 精英击杀数×每精英加成 + 头目击杀数×每头目加成)
            × (1 + 护甲HP%) × 生命上限惩罚系数)        # 仅 HP 计算取整；惩罚保底 = 无惩罚上限 × 50%
ATK = 武器伤害 × 基础攻击倍率 × (1 + 护甲近战/远程%) × 力量(×2 如有)   # 全程浮点
基础攻击倍率 = 1 + 每层攻击加成×(floor-1) + 精英击杀数×1% + 头目击杀数×每头目攻击加成
移速 = 4 × (1+护甲移速%) × 迅捷(×2 如有) × 霜冻(×0.4 或 ×0.6) → 再 × 0.75 全局倍率
```
- 换甲百分比机制：换甲前后当前生命保持相同百分比（新HP = round(旧当前/旧上限 × 新上限)）。
- 玩家伤害减免仅来自护甲 DR；受击 = round(伤害×(1−DR))。
- 暴击为**命中时独立判定**：近战暴击来自护甲（战袍/凋零之甲，×2.5），远程暴击来自武器（精英之弓 ×3）。

### 生命上限惩罚（V1.0.6.1 新增）
| 触发 | 扣减 | 说明 |
|------|------|------|
| 楼层重置（死亡复活 / 暂停菜单手动重置） | 生命上限 ×0.90（扣 10%） | 手动重置同时消耗 1 条生命 |
| 退出游戏后继续（存档 scene_state 为 combat/reward，楼层不重置） | 生命上限 ×0.95（扣 5%） | — |
| 保底 | 不低于无惩罚上限的 50%（MAX_HP_PENALTY_FLOOR=0.50） | — |

惩罚随存档永久保存（`max_hp_mult` 累乘）；新游戏/游戏结束重开自动恢复满上限；扣减后当前 HP 立即压回新上限内。

## 九、楼层缩放公式

```
普通/精英：HP/ATK = 初始 × (1 + 难度倍率 × (floor−1))        难度倍率：默认12% / 冒险15% / 末日18%
头目BOSS： HP/ATK = 初始 × 难度BOSS倍率(1.0/1.2/1.5) × (1 + (Floor−1) × 难度倍率/3)
           第 10 层生成额外 ×0.75（head_boss_floor_hp_mult，V1.0.6.2）
首领：     HP = 6000 × 难度BOSS倍率（不吃楼层公式）；承伤上限 30/100
冷却：     攻击/技能冷却不随楼层缩放（V1.0.5.10 移除缩放）；BOSS 技能CD ×(1.0/0.9/0.8)
```
BOSS 楼层（10/20/30）非 BOSS 房间杂兵按真实楼层缩放（V1.0.5.14 修复）。

### 多房间架构（V1.0.5+）
- 每个房间独立 20×15 网格；出生点房间 2-4 个传送门（BOSS 楼层固定 4 分支），双向连接；房间内随机墙 4-8 个（避开出生点/传送门/刷怪笼）。
- 传送倒计时：普通传送门 4 秒（PORTAL_TRAVEL_DELAY）；通往下一楼层 5 秒（FLOOR_PORTAL_TRAVEL_DELAY）。
- 背包空位阻断传送：剩 1 格「背包将满，无法传送！」；0 格「背包已满，无法传送！」。
- 击败当前房间所有怪物 → 通往下一楼层的传送门激活（特殊宝藏房间不参与判定）。
- 进入战斗先经 3 秒刷怪倒计时（SPAWN_DELAY_SEC=3.0）。

## 十七、存档系统
