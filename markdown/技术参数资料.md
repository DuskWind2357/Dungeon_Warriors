## 楼层缩放

```
普通/精英: HP = int(base×1.07^(f-1)) + ⌊(f-1)/5⌋×10
           ATK = int(base×1.07^(f-1)) + ⌊(f-1)/5⌋×2
头目/首领: 固定数值, 不受缩放
```
