# Dungeon Warriors V1.0.5 — 技术参数资料

---

## 玩家

| 属性 | 值 | 成长（默认/冒险/末日） |
|------|-----|------|
| 基础 HP | 100 | 每层 +5/+8/+10, 每头目 +10/+15/+20, 每精英 +2/+3/+5 |
| 基础攻击倍率 | 1.0 | 每层 +4%/+5%/+6%, 每头目击杀 +9%/+12%/+15%, 每精英击杀 +1% |
| 移速 | 4 px/f | 迅捷 ×2, 霜冻 ×0.6, 护甲加成 |
| 复活（生命条数） | 3 条上限 | 神秘奖励可+1, 已满不再增加 |

HP 公式: `round((100 + (floor-1)×hp_per_floor + elite×hp_per_elite + boss×hp_per_boss) × (1 + armor_pct))`（按难度取值）

ATK 公式: `武器伤害 × 基础攻击倍率 × 护甲加成(如有) × 暴击(如有, 命中时判定) × 力量(如有)`

换甲百分比机制: `新当前生命 = round((旧当前生命 / 旧总上限) × 新总上限)`（换甲前后生命值百分比保持不变）

### V1.0.5 多房间架构

- 每个房间为独立的20×15网格，切换房间时整个画面变化
- 出生点房间有2-4个传送门，分别通往不同战斗房间
- 传送门双向连通，使用专用贴图渲染
- 击败当前房间所有怪物 → 通往下一楼层传送门激活
- 房间内部无障碍物

### V1.0.5.6 BOSS楼层架构（10/20/30）

- 结构统一为 5 房间：出生点 + 增强战斗房间（10/20层2个，30层3个）+ BOSS战房间；10/20层另有1个特殊宝藏房间，30层没有
- 出生点房间固定4个传送门（左/右/上/下），通往各增强房间与BOSS战房间；增强房间仅与出生点连接（互不连通）
- BOSS战房间封印：出生点与全部增强房间清空前不可进入，红字"传送门已被封印！"
- BOSS战：10/20层随机2名头目BOSS（近战+远程各一，HP/ATK应用头目BOSS楼层公式）；30层高塔之主（HP6000×难度倍率，单次承伤30/每秒承伤100）
- 特殊宝藏房间（10/20层）：需"藏宝室钥匙"（BOSS战必掉，两名BOSS仅掉一次）解锁；解锁后与普通传送门同一套音效和交互，贴图始终为 `icon/block/传送门.webp`
- BOSS楼层的出生点/增强战斗房间按第一层标准刷怪（6+2，乘难度倍率）
- 通关传送门位于出生点房间中央，全层战斗类房间清空后激活（特殊宝藏房间不参与判定）

刷怪数量（普通+精英，乘难度倍率）：1-4层6+2 / 5-9层8+3 / 11-19层12+4 / 21-29层18+6；史莱姆≤总数1/4。
