# Dungeon Warriors V1.0.3 — 游玩说明

---

## 简介

2D 像素风地牢肉鸽游戏。挑战 **30 层**高塔，击败首领 **高塔之主** 通关。

---

## 操作

| 按键 | 功能 |
|------|------|
| WASD | 移动 |
| 鼠标左键 | 攻击（自动朝向鼠标） |
| 鼠标右键 | 远程攻击 |
| 1-5 数字键 | 快捷使用消耗品（面包/生命/力量/迅捷/隐身） |
| E | 拾取物品 |
| B | 背包（64格） |
| ESC | 存档并返回主菜单 |

---

## 背包

- **左键**：拿起/放下物品
- **右键**：弹出菜单（使用/销毁 或 替换/销毁）
- **1-5 快捷键**：无需打开背包即用消耗品，数量提示绿(≥3)/黄(2)/红(≤1)

---

## 难度

菜单 → 设置 → 选择难度：

| 难度 | 刷怪 | 移速 | CD |
|------|------|------|-----|
| 默认 | 1.0× | 0.75× | 1.25× |
| 冒险 | 1.5× | 1.0× | 1.0× |
| 末日 | 2.0× | 1.25× | 0.75× |

---

## 战斗

- **双武器槽**：近战 + 远程各一把，自动切换
- **暴击**：战袍/凋零之甲/精英之弓触发，"暴击！"提示
- **斩杀**：杀戮之弩秒杀，"斩杀！"提示
- **吸血**：冷酷战甲/凋零之甲近战回血
- **过热**：机械链锯/机械弩连续攻击后需冷却
- **多重箭**：幻术师之弓45%三箭齐发

---

## 楼层

- 离开出生点 → 3秒倒计时 → 怪物出现
- 击败全层怪物 → 传送门出现 → 停留3秒 → 下一层
- 传送前背包需 ≥2 空格

---

## 掉落

| 怪物 | 掉落 |
|------|------|
| 普通 | 10% 面包, 5% 药水 |
| 精英 | 30% 面包, 15% 药水 |
| 头目 | 80% 面包, 80% 药水, **100% 高一级装备** |

---

## 奖励

通关楼层四选一：近战升级/远程升级/护甲升级/神秘奖励。满级45%出特殊装备。
