## 三、系统层

### combat.py — 战斗计算

所有攻击计算使用**浮点数**，仅在 HP 变更时 `round()` 取整。

```
melee_atk = (weapon_atk + base_bonus) × (1 + armor_melee_pct) × (strength ? 2 : 1)
ranged_atk = (weapon_atk + base_bonus) × (1 + armor_ranged_pct) × (strength ? 2 : 1)
hp = round((100 + floor_bonus + boss_bonus + elite_bonus) × (1 + armor_hp_pct))
```

**连击**：spear combo=3 (攻击3次后冷却)
**过热**：`if ++cnt >= overheat_count: cooldown = overheat_cd; cnt = 0`
**暴击**：`if random() < armor.crit_chance: damage *= armor.crit_mult`
**秒杀**：`if random() < weapon.instakill[type]: monster.hp = 0`
**三重射击**：`if random() < triple_shot_chance: count = 3`

### pathfinding.py — A* 寻路

- 曼哈顿启发式, 4方向邻域
- 路径简化: Bresenham 直线可见性跳过中间节点
- 重算间隔: 追击 0.5s, 徘徊按需
- Fallback: 随机方向移动

### floor_manager.py — V1.0.5 多房间楼层生成

- 每个房间为独立的20×15网格（与原版单楼层相同大小）
- `generate_floor(floor_num)` 返回 `FloorLayout`（含多个 `Room`）
- 每个 `Room` 持有独立 `grid`、`portals`、`spawn_pos`
- 出生点房间有2-4个传送门，双向连接战斗房间
- 传送门在墙壁上：左墙/右墙/上墙/下墙，偏移位置对应
- 击败当前房间所有怪物 → 通往下一楼层传送门激活
- 房间内部无障碍物（纯空房间）
- **主题系统**: `get_theme(floor)` → dungeon(1-9) / snow(11-19) / hell(21-29) / boss(10,20,30)
- 固定刷怪表: 1-4(6+2), 5-9(8+2), 11-19(12+4), 21-29(18+6)，乘以难度 spawn_mult
- 主题精英池: 地牢=精英僵尸/精英骷髅, 雪地=冰霜僵尸/流髑, 地狱=除雪地外全部
- 史莱姆上限: ≤1/4总数 (超额替换不删除)
- 地狱陷阱: 可行走格 10% 置为 4 (排除出生点)

### 陷阱/霜冻 (V1.0.4)

```
陷阱: grid值=2, 可行走; 玩家踩上每秒 -5 固定HP(无视DR) + 燃烧音效
霜冻: status_effects["frost"], 生效期间 total_speed × 0.6
  冰霜僵尸 近战命中 → frost 4s
  流髑 投射物命中   → frost 3s (普攻与三连箭均附加)
```

### 奖励流程 (V1.0.4 P2 重做)

```
确认时: 所需空位 = 复活0 / 单件1 / 药水组2
  空位不足 → 禁止确认(红色提示)
  足够 → 全部 add_item 直接入背包(不自动装备)
复活奖励: <3条 → +1; 已满 → 仅红字提示"已达上限"
传送门: 剩余空位≤1 阻断传送(文案: 将满/已满) — 保证奖励空间
pending_rewards 延迟补发机制已删除
```

### 头目掉落 (V1.0.4 P2)

```
同类型玩家装备 T5满级 或 特殊 → 掉落必为该类型特殊池随机
否则 → 原"高一级"逻辑 (T+1, 上限T5)
```

### 换甲百分比机制 (inventory._equip_armor)

```
ratio = 当前生命 / 换甲前总上限
装备新甲后: 当前生命 = round(ratio × 新总上限)  (clamp 0..new_max)
效果: 换甲前后生命值百分比不变
```

### save_system.py — 存档

JSON 格式, 保存: player(HP/武器/护甲/buffs/boss_kills/elite_kills), backpack, revive, floor, scene_state。

## 四、渲染层

- 怪物/玩家/弹射物均使用精灵图标
- 图标按名称映射, 文件名不匹配时 fallback 到几何图形
- 弹射物: 箭矢按飞行方向旋转, 火球固定
- HUD: 左上 `生命值/当前楼层/剩余生命条数` (雪地/地狱层白色, 其余深灰), 右上 Buff/状态效果
- **主题贴图 (V1.0.4)**: 按主题加载贴图集, 变种概率固定种子防闪烁
  - 地牢: 地砖变种20%, 墙变种1 10% + 变种2 10%
  - 雪地: 地砖变种20%, 墙变种20%
  - 地狱: 地砖变种20%, 陷阱格专用贴图
  - 头目: 无变种, 磁石出生点
- BUFF HUD 统一"名称 秒数"格式: 燃烧橙/霜冻淡蓝/力量紫/迅捷蓝/回复红/隐身金/凋零黑

## 六、平衡公式

```
玩家 HP = round((100 + floor×5 + boss×10 + elite×2) × (1 + armor_hp_pct))
玩家 ATK = weapon_atk + elite//5 + boss  (浮点, HP变更时取整)
怪物 HP = int(base × 1.07^(floor-1)) + ⌊(floor-1)/5⌋×10  (仅普通/精英)
怪物 ATK = int(base × 1.07^(floor-1)) + ⌊(floor-1)/5⌋×2
伤害减免 = raw_damage × (1 - DR)
```
